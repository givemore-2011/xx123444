# DIY 装机价格面板

监控 CPU、显卡、主板、内存、固态硬盘、机械硬盘、电源、显示器八类硬件的参考价，
按品类看价格曲线、品牌对比、涨跌和行情资讯。数据源是中关村在线公开报价库，每天采一次。

## 快速开始

| 想做什么 | 怎么做 |
|---|---|
| 看盘 | 双击 `index.html` |
| 抓一次最新价格 | 双击 `run.bat`，约 3 分钟，抓完自动打开面板 |
| 每天自动抓 | 右键 `install_task.ps1` → 使用 PowerShell 运行（每天 09:30） |
| 手机上一起看 | `python app.py serve --lan`，同网段手机打开内网 IP:8765 |

## 命令行

```
python app.py            采集 + 生成 + 打开看板
python app.py collect    只采集硬件价格
python app.py news       只采集行情资讯
python app.py build      只重新生成看板数据
python app.py serve      起本地服务（默认 127.0.0.1:8765）
python app.py all        全流程，不自动开浏览器
```

## 文件

| 文件 | 作用 |
|---|---|
| `app.py` | 统一入口，所有命令都从这里走 |
| `collector.py` | 采集八类硬件价格，写入 SQLite |
| `news.py` | 抓科技媒体 RSS 筛硬件资讯 |
| `build_board.py` | 数据库 → 看板数据 |
| `index.html` | 面板本体，双击就能开 |
| `run.bat` | 一键采集并打开 |
| `install_task.ps1` | 注册每日定时任务 |
| `data/prices.db` | 价格历史库 |
| `data/collect.log` | 每次采集的成功/失败记录 |
| `config.local.json` | 京东密钥（可选，见下） |
| `jd_probe.py` | 京东联盟接口自检（可选） |

## 筛选口径

只保留当代主流型号，停产老货会被规则挡掉：

| 品类 | 门槛 | 价位段 |
|---|---|---|
| CPU | Intel 12 代起 / 锐龙 5000 系起 | 700–3,200 |
| 显卡 | RTX 40/50 系、RX 7000/9000 系 | 1,500–6,500 |
| 主板 | B660/B760/B860、Z690–Z890、X670–X870、A620 | 600–2,800 |
| 内存 | DDR5 或 DDR4 3200 以上 | 250–2,500 |
| 固态硬盘 | NVMe / M.2 / PCIe 接口 | 200–2,000 |
| 机械硬盘 | 4TB / 8TB | 350–2,500 |
| 电源 | 550W 以上 | 300–1,500 |
| 显示器 | 一线品牌 | 700–4,500 |

改品牌白名单、价位段、页数，都在 `collector.py` 顶部的 `CATEGORIES` 里。

## 京东联盟 API（可选，多数情况不需要）

想接京东到手价才需要。拿到 AppKey / AppSecret 后填进 `config.local.json`，跑
`python jd_probe.py`，它会告诉你卡在签名、权限还是 IP 白名单。

现在京东那条线没接，原因是商品页有验证码墙，官方 API 要推广位（网站备案 / APP / 社媒账号）才能拿密钥。

> `config.local.json` 里有密钥，别放进聊天窗口、别截图、别共享整个文件夹。

## 已知局限

- **参考价不是到手价**。ZOL 给的是渠道参考价，比京东券后价偏低且更新有滞后，
  看趋势和相对位置够用，直接拿去下单比价会失真。
- **固态硬盘是系列维度**。ZOL 把一个系列的多容量合并成价格区间，面板取最低容量价。
- **曲线要累积**。第一天只有一个点，连续跑 2 天以上才成形。
- **整机水位是粗估**。八类中位价相加，用来看市场量级，不是能下单的配置单。
- **没有性能分**。性价比需要一张"型号→性能"对照表，目前没做，避免用估算值误导判断。
